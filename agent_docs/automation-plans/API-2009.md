## Test contract

| Item | Decision |
|---|---|
| Objective | `POST /rides` with a ride option id that does not exist fails validation |
| Preconditions | Fresh isolated sandbox session reset by `ApiTestCase.resetSandboxStates`; default states; bearer token from `ApiTestCase.obtainToken`; no ride is created before the request |
| Request | `POST /rides` body `{"from":"Oak Avenue","to":"Market Street","rideOptionId":999}` with the token and `X-Sandbox-Session` |
| Expected result | 400 with `error` "Unknown ride option 999" |
| Contract source | `openapi.yaml` `/rides` post `400` (ErrorResponse) |
| Assigned test | Allure ID `2009`; inventory of `@AllureId` in `api-tests/src` shows 2000-2004, 2006-2008, so 2009 is free |
