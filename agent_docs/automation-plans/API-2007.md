## Test contract

| Item | Decision |
|---|---|
| Objective | `POST /rides` with an empty `to` fails validation and leaves the session without an active ride |
| Preconditions | Fresh isolated sandbox session reset by `ApiTestCase.resetSandboxStates`; bearer token from `ApiTestCase.obtainToken`; no ride is created before the request |
| Request | `POST /rides` body `{"from":"Oak Avenue","to":"","rideOptionId":1}`, then `GET /rides/active`, same token and `X-Sandbox-Session` |
| Expected result | 400 with `error` "Both from and to are required"; then 404 with `error` "No active ride" |
| Contract source | `openapi.yaml` `/rides` post `400` (ErrorResponse), `/rides/active` get `404` (ErrorResponse, example `No active ride`) |
| Assigned test | Allure ID `2007`; inventory of `@AllureId` in `api-tests/src` shows 2000-2004, 2006, 2008, so 2007 is free |
